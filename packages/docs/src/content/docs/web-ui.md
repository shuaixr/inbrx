---
title: Web UI
description: Inspect captured messages in the inbrx Web UI.
---

The Web UI runs at `http://127.0.0.1:3000` by default.

Use it to:

- Browse captured messages.
- Search messages.
- Inspect message headers and body content.
- Download captured attachments.
- Delete individual messages.
- Clear all retained messages.

The Web UI updates as new messages arrive through the local SMTP server.
